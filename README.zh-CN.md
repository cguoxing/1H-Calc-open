把工程收费标准装进微信，一句话算出有据可查的报价。

易计算是一款微信小程序。输入计费额、选择专业和复杂程度，即可按国家与地方收费标准计算工程取费，并一键导出带公式、系数和标准文号的 PDF 报价单。


由 [1+H ARCH](https://www.1h-arch.com) 开发并开源。

## 计算依据

`standards/` 目录收录了 24 份收费文件的整理稿（Markdown），每个计算器的数据都能对回原文，主要包括：

- 《工程勘察设计收费标准》计价格[2002]10 号
- 《招标代理服务收费管理暂行办法》计价格[2002]1980 号、发改办价格[2011]534 号
- 《建设工程监理与相关服务收费管理规定》发改价格[2007]670 号
- 《基本建设项目建设成本管理规定》财建[2016]504 号
- 广东、北京、上海等地方标准，以及 2024 广东服务成本取费导则

2015 年起工程服务收费已全面放开（发改价格[2015]299 号）。计算结果是报价与谈判的参考基准，**不构成合同金额**，正式报价请以双方约定为准。

## 快速开始

环境要求：[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)、Node.js 18 及以上（仅用于运行测试，项目没有 npm 依赖）。

1. 克隆仓库：

   ```bash
   git clone https://github.com/cguoxing/1H-Calc-open.git
   ```

2. 用微信开发者工具导入项目根目录。
3. 把 `project.config.json` 里的 `appid` 改成你自己的小程序 AppID（或选择测试号）。
4. 编译预览即可使用。计算全部在本机完成，不依赖后端。

## 后端架构：从微信云开发到自建备份

易计算的**全部计算都在小程序本机完成，不依赖任何后端**。后端只服务于一个可选功能：登录用户的账户与历史数据备份。这部分经历了一次演进。

**最初方案 —— 微信云开发（免费云函数 + 云数据库）。** `cloudfunctions/` 目录保留了这套实现：

- `getOpenid`：通过云调用换取用户 OpenID；
- `userAccount`：按 openid 唯一存储用户档案（`users` 集合，注册 / 查询 / 判断是否已注册）；
- `syncData`：把计算历史同步到云数据库（`calc_history` 集合）；
- `generatePDF`：PDF 报价单辅助（实际 PDF 在前端 `pdf-generator.js` 生成）。

**现方案 —— 西部数码虚拟主机上的 PHP 备份端。** 由于用户和数据量都不大，后来改成了更简单、成本更低、也更便于自己掌控的方案：在已有的西部数码虚拟主机上部署一个**无需数据库**的 PHP 接口（`west-host-backup/`），用户数据以 JSON 文件按人存档。鉴权沿用微信机制——小程序每次备份前调用 `wx.login` 取一次性 code，由服务端换取 openid，因此**小程序端不保存任何密钥**。

两套方案二选一即可：仓库默认走 `west-host-backup/` 的自建备份，`cloudfunctions/` 作为参考保留、默认未启用。若你更习惯微信云开发，把 `cloudfunctions/` 部署到自己的云环境、并在前端改回云调用即可。

## 测试

```bash
npm run check
```

一条命令依次运行 9 项检查：JS 语法、JSON 合法性、WXSS、页面与资源一致性（含 WXML 事件绑定）、计算结果、页面逻辑、数据完整性与备份逻辑、PDF 格式。

## 数据与隐私

- 历史记录、项目等数据默认只保存在用户手机本地。
- 只有注册并同意隐私政策的用户才会自动备份，且仅在数据变化时上传。
- 用户可在「用户设置 → 账户与数据备份」中注销并删除云端备份。

### 自建备份服务（west-host-backup）

`west-host-backup/` 是一套无需数据库的 PHP 备份接口，适合普通虚拟主机：

1. 上传 `api.php`、`monitor.php`，将 `config.sample.php` 复制为 `config.php` 并填写小程序 AppID、AppSecret、随机盐和监控密码哈希。
2. 在微信公众平台把接口域名加入 request 合法域名。
3. 修改 `miniprogram/utils/server-backup-config.js` 中的 `apiUrl` 指向你的服务器；不需要备份时把 `enabled` 改为 `false`。

接口用 `wx.login` 的一次性 code 在服务端换取 openid 鉴权，小程序代码里不保存任何密钥。详见 [west-host-backup/README.md](west-host-backup/README.md)。

**注意：** `config.php` 含 AppSecret，已在 `.gitignore` 中排除，切勿提交；真实用户备份数据（`west-host-backup/data/`）也不包含在本开源仓库中。
