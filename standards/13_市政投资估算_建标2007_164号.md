# 市政工程投资估算编制办法

**文号**: 建标[2007]164号
**发文**: 建设部
**日期**: 2007年

---

## 一、适用范围

适用于新建、扩建、改建的市政工程项目投资估算编制。

## 二、投资估算组成

```
市政工程项目总投资 = 工程费用 + 工程建设其他费用 + 预备费 + 建设期利息 + 铺底流动资金
```

### 工程费用
- 建筑工程费
- 安装工程费
- 设备及工器具购置费

### 工程建设其他费用（本办法重点规定）

| 序号 | 费用名称 | 说明 |
|:--:|------|------|
| 1 | 建设用地费 | 征地/拆迁/补偿 |
| 2 | 建设管理费 | 建设单位管理费/监理费 |
| 3 | 前期工作费 | 可研/环评/勘察/设计 |
| 4 | 研究试验费 | 特殊试验检测 |
| 5 | 勘察设计费 | 按2002/10号 |
| 6 | 专项评价费 | 环评/安评/水保/节能 |
| 7 | 场地准备及临时设施费 | 三通一平/临建 |
| 8 | 工程保险费 | 建安费×费率 |
| 9 | 市政公用设施费 | 配套/接驳 |
| 10 | 生产准备及开办费 | 人员培训/工器具 |
| 11 | 联合试运转费 | 设备调试 |

## 三、市政工程特有的其他费

| 费用项目 | 说明 |
|----------|------|
| 管线迁改费 | 施工范围内各类管线的迁移/保护 |
| 交通疏解费 | 施工期间交通组织/导改 |
| 绿化迁移费 | 施工范围内的树木/绿地迁移 |
| 临时用水用电 | 施工临时水电接入 |
| 既有设施保护费 | 对邻近建（构）筑物的监测保护 |

## 四、产品开发注意事项

1. 市政项目其他费项目比民用建筑更多（管线迁改/交通疏解等）
2. 可在"工程建设其他费汇总"模块中区分"民用建筑"和"市政工程"两套模板
3. 建标[2007]164号虽未规定具体费率数字，但提供了完整的费用科目体系
