# 城乡规划设计计费指导意见（2025修订版）

**发文**: 中国城市规划协会
**日期**: 2025年
**版本**: 2025修订版（最新）

> 来源: 中规协官方 / xa-du.com / geesic.com
> 注: 该版为最新修订，部分内容可能仍在征求意见中

---

## 一、修订重点

相比2017版，2025版重点新增/修订以下内容：

### 1. 适应存量更新时代
- 新增**城市更新专项规划**计费标准
- 新增**城市体检评估**计费标准
- 优化旧区改造/城中村改造规划计费

### 2. 新增韧性城市相关内容
- 新增**韧性城市专项规划**计费
- 新增**防灾减灾专项规划**计费
- 新增**气候适应性规划**计费

### 3. 数字化/智慧化
- 新增**数字孪生城市**计费
- 新增**CIM平台规划**计费
- 新增**智慧城市顶层设计**计费

### 4. 生态/双碳
- 新增**碳达峰碳中和专项规划**计费
- 新增**生态修复规划**计费
- 新增**国土空间生态修复**计费

## 二、新增规划类型的计费框架（基于行业信息汇总）

| 规划类型 | 计费方式 | 参考价格区间 |
|----------|:------:|:----------|
| 城市更新专项规划 | 按面积+规模 | 50~200万 |
| 城市体检评估 | 按城市规模 | 30~120万 |
| 韧性城市专项规划 | 按面积+规模 | 40~150万 |
| 数字孪生城市 | 按面积+应用深度 | 80~300万 |
| 碳达峰碳中和专项 | 按城市规模 | 40~120万 |
| 国土空间生态修复 | 按面积 | 30~150万 |
| 城中村改造规划 | 按面积 | 50~200万 |
| 老旧小区改造规划 | 按户数/面积 | 20~80万 |

## 三、与2017版的主要变化

| 维度 | 2017版 | 2025版 |
|------|:----:|:----:|
| 规划类型数 | 30+ | 40+ |
| 城市更新 | 初步涉及 | 独立章节 |
| 数字化 | 未涉及 | 新增数字孪生/CIM |
| 双碳 | 未涉及 | 新增碳达峰碳中和 |
| 韧性城市 | 未涉及 | 新增专项 |
| 国土空间规划衔接 | 初步 | 全面对齐 |

## 四、产品开发注意事项

1. 2025版为最新标准，建议作为规划模块默认依据
2. 城市更新、城中村改造等类型与公司战略高度相关
3. 完整费率表建议采购中规协官方出版物
4. 如正式稿尚未发布，可先用2017版 + 行业调研数据补充
