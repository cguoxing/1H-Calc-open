# 上海市建设工程造价服务和工程招标代理服务收费标准

**文号**: 沪建计联[2005]834号 / 沪价费[2005]056号
**发文**: 上海市建设和交通委员会、上海市物价局
**日期**: 2005年12月20日
**执行**: 2006年1月1日起

> 来源: 上海市经信委官网 (sheitc.sh.gov.cn)

---

## 一、核心规则

- **收费方式**: 差额定率累进
- **浮动幅度**: 上下不超过10%（较国标20%更严格）
- **付费方**: 谁委托谁付费
- **分类**: 计件收费 + 计时收费

## 二、计时收费标准

| 人员资格 | 收费标准 |
|----------|:------:|
| 高级职称/注册造价工程师/招标工程师 | 300元/小时 |
| 中级职称/工程造价人员/招标代理人员 | 200元/小时 |
| 其他一般专业人员 | 100元/小时 |
| 特殊专业技术人员 | 双方协商 |

## 三、计件收费——差额定率累进费率表（附件2摘要）

上海标准按**总投资**为基数，覆盖以下服务：

| 服务项目 | 收费基数 |
|----------|:------:|
| 编制项目投资估算 | 总投资 |
| 设计概算 | 总投资 |
| 编制施工图预算/工程量清单/标底 | 建安造价 |
| 勘察/设计/施工监理/施工招标代理 | 总投资/中标额 |
| 施工阶段全过程造价控制 | 建安造价 |
| 工程造价审核 | 核增+核减 |
| 钢筋及预埋件重量计算 | 按吨 |

> 注：完整费率表需查阅沪建计联[2005]834号原文附件2。网页正文未包含具体费率数字，但提供了分段框架：100万以下/100~500/500~1000/1000~3000/3000~5000/5000~10000/10000以上，各服务项目费率不同。

## 四、与国家标准的主要差异

| 对比维度 | 国标(1980号) | 上海(834号) |
|----------|:----------:|:----------:|
| 计费基数 | 中标金额 | 总投资/建安造价 |
| 浮动幅度 | ±20% | ±10% |
| 计费方式 | 差额定率累进 | 差额定率累进 |
| 造价服务 | 不含 | 含（设计概算/预算/清单/全过程控制） |

## 五、产品开发注意事项

1. 上海地区项目优先使用834号，需录入完整的各服务项目费率表
2. 计费基数不同于国标（总投资 vs 中标金额）
3. 浮动幅度更严（±10% vs ±20%）
