# 广东省建筑信息模型（BIM）技术应用费用计价参考依据

**文号**: 粤建科[2018]136号
**发文**: 广东省住房和城乡建设厅
**日期**: 2018年7月24日

> 来源: 广东省住建厅官网 / gdtd.net / 各市转发文件

---

## 一、适用范围

适用于新建：
- 工业与民用建筑工程
- 市政道路工程
- 轨道交通工程
- 地下综合管廊工程
- 园林景观工程

其余类型和改扩建项目可酌情参考。

## 二、计价方式

| 工程类型 | 计价基数 | 费率/单价 |
|----------|:------:|:--------:|
| 工业与民用建筑 | 建筑面积 | **30元/m²**（面积<2万m²按2万m²计） |
| 市政道路 | 建安费 | **0.3%** |
| 轨道交通 | 建安费 | **0.25%** |
| 地下综合管廊 | 建安费 | **0.25%** |
| 园林景观 | 建安费 | **0.3%**（造价<1亿按1亿计） |

## 三、应用阶段调整系数

| 应用阶段 | 系数 |
|----------|:---:|
| 仅设计阶段 | 0.5~0.6 |
| 设计+施工 | 1.0 |
| 仅施工阶段 | 0.4~0.5 |
| 运维阶段 | 0.3~0.4 |
| 全生命周期 | 1.2~1.5 |

## 四、应用专业调整系数

| 专业范围 | 系数 |
|----------|:---:|
| 仅建筑 | 0.4 |
| 建筑+结构 | 0.6 |
| 建筑+结构+机电 | 1.0 |
| 全专业（含精装/景观/幕墙等） | 1.2 |

## 五、产品开发注意事项

1. 全国已有20+省市发布BIM计价标准（宁夏/上海/浙江/河南/湖南等），费率各有差异
2. 广东版是国内较早且应用最广的省级标准
3. 计算逻辑：基价 × 阶段系数 × 专业系数
4. 需支持多工程类型切换
