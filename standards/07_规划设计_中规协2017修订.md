# 城乡规划设计计费指导意见（2017修订版）

**发文**: 中国城市规划协会
**日期**: 2017年7月（重庆发布）
**版本**: 2017修订版

> 来源: 中规协官方发布 / chanyeguihua.com / 各文档平台
> 注: 完整费率表篇幅较大（数十页），以下为框架和核心计费逻辑

---

## 一、修订背景

- 2004版《城市规划设计计费指导意见》已不适应行业发展
- 2016年12月中规协启动修订，2017年7月在重庆发布
- 新增乡村规划、城市更新、城市设计等新类型
- 计费体现"优质优价"原则

## 二、城市规模分类

按《国务院关于调整城市规模划分标准的通知》(国发[2014]51号)：

| 类型 | 城区常住人口(万人) |
|:----:|:---------------:|
| 超大城市 | ≥1000 |
| 特大城市 | 500~1000 |
| 大城市 | 100~500 |
| 中等城市 | 50~100 |
| 小城市 | <50 |

## 三、主要规划设计类型及计费框架

### 1. 城市总体规划

| 城市规模 | 计费基价(万元) |
|:------:|:----------:|
| 小城市 | 60~80 |
| 中等城市 | 80~120 |
| 大城市 | 120~200 |
| 特大城市 | 200~350 |
| 超大城市 | 350~600 |

> 不含专题研究。如需相关专题研究应单独计费：超大城市30万/个、特大城市25万/个、大城市20万/个。

### 2. 城市近期建设规划

计费基价：40万元（基准）

### 3. 控制性详细规划

| 城市规模/区域 | 计费方式 | 参考单价(元/ha) |
|:----------|:------:|:-----------:|
| 城市新区 | 按面积 | 2,500~4,000 |
| 城市旧区/更新区 | 按面积 | 3,500~5,500 |
| 开发区/园区 | 按面积 | 2,000~3,500 |

### 4. 修建性详细规划

| 类型 | 计费方式 | 参考单价(元/ha) |
|:---:|:------:|:-----------:|
| 居住区 | 按面积 | 8,000~15,000 |
| 城市重点地段 | 按面积 | 12,000~25,000 |
| 公园/绿地 | 按面积 | 6,000~12,000 |

### 5. 城市设计

| 层次 | 计费方式 | 参考单价 |
|:---:|:------:|:------:|
| 总体城市设计 | 按面积 | 500~1,500元/ha |
| 片区城市设计 | 按面积 | 2,000~5,000元/ha |
| 地段/节点城市设计 | 按面积 | 5,000~15,000元/ha |

### 6. 交通/市政专项规划

| 类型 | 计费方式 | 参考价 |
|:---:|:------:|:----:|
| 综合交通规划 | 按城市规模 | 60~200万 |
| 单项交通规划 | 按规模 | 30~80万 |
| 市政专项 | 按规模 | 40~120万 |

### 7. 乡村规划（2017新增）

| 类型 | 计费方式 | 参考价 |
|:---:|:------:|:----:|
| 村庄规划 | 按村 | 5~20万/村 |
| 美丽乡村规划 | 按村 | 10~30万/村 |
| 传统村落保护规划 | 按村 | 15~40万/村 |

## 四、产品开发注意事项

1. 2017版大幅扩展了规划设计类型（从2004版的10+类扩展到30+类）
2. 新增乡村规划、城市设计、城市更新、海绵城市专项等
3. 计费与城市规模强相关，需先选择城市规模等级
4. 完整费率表建议采购中规协官方出版物
