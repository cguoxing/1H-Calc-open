## 📐 核心计算公式速查

### 工程设计收费（计价格[2002]10号）
```
收费基价 = 直线内插(计费额, 基价表)
工程设计收费 = 收费基价 × 专业调整系数 × 复杂程度系数 × 附加调整系数
总收费 = 工程设计收费 × 阶段比例 × 折扣 + 其他收费 + 增值税
```

### 附加系数合并（2024 广东导则）
```
2002版（连乘）：Π Cᵢ
2024版（累加减基）：Σ Cᵢ - n + 1
```

### 造价咨询费（粤价函[2011]742号）
```
总费用 = Σ(各档计费额 × 对应费率)  ← 差额定率分档累进
结算审核 = 送审造价 × 2.8‰ + 核减额 × 5%
```

### 工程勘察费（2005 手册）
```
基本勘察费 = 收费基价 × 复杂程度系数 × 场地复杂程度系数 × 附加调整系数
```
