# 广东省政府采购中心收费标准（2023版）

**来源**: 广东省政府采购中心
**日期**: 2023年

---

## 差额定率累进收费标准

| 中标金额(万元) | 货物/服务 | 工程 |
|:----------|:------:|:---:|
| ≤100 | 1.5% | 1.0% |
| 100~500 | 1.1% | 0.7% |
| 500~1000 | 0.8% | 0.55% |
| 1000~5000 | 0.5% | 0.35% |
| 5000~10000 | 0.25% | 0.2% |
| 10000~50000 | 0.05% | 0.05% |
| 50000~100000 | 0.035% | 0.035% |
| 100000~500000 | 0.008% | 0.008% |
| 500000~1000000 | 0.006% | 0.006% |
| >1000000 | 0.004% | 0.004% |

> 广东省采购中心自定标准，本质上是1980号+534号合并后的费率表

## 收费上限

| 类型 | 上限(万元) |
|:----:|:---------:|
| 货物 | 350 |
| 服务 | 300 |
| 工程 | 450 |

## 产品开发注意事项

1. 广东省采购中心标准已合并1980号和534号
2. 可作为"广东默认"选项
3. 与国家标准差异不大，主要区别在于已整合降费条款
