# 海绵城市建设工程取费标准（参考）

**来源**: 湖北省住建厅2024版 / 各省市消耗量定额

---

## 一、国家层面

海绵城市建设尚无全国统一的专项设计取费标准，各地自行制定。一般参照：
- 计价格[2002]10号市政工程设计费 + 海绵专项附加
- 或按《市政工程投资估算编制办法》(建标[2007]164号)

## 二、湖北省2024版（参考）

《湖北省海绵城市工程消耗量定额及全费用基价表》（2024）共六章：

| 章节 | 内容 |
|:--:|------|
| 第一章 | 透水铺装 |
| 第二章 | 绿色屋顶 |
| 第三章 | 生物滞留设施及湿地湿塘 |
| 第四章 | 蓄水模块/雨水收集 |
| 第五章 | 植草沟/渗透管渠 |
| 第六章 | 其他海绵设施 |

> 例如：生物滞留设施基层处理定额28.5工日/100m²，蓄水模块安装定额16.3工日/100m²

## 三、设计费取费方式（行业惯例）

| 方式 | 说明 |
|------|------|
| 按市政设计费附加 | 在市政设计费基础上加收10%~20%海绵专项 |
| 按面积计费 | 0.5~2元/m²（仅海绵专项设计） |
| 按投资额计费 | 海绵设施投资 × 3%~5% |

## 四、海绵城市专项规划

参考中规协计费指导意见：
- 海绵城市专项规划：30~80万（按城市规模）
- 海绵城市建设实施方案：20~50万

## 五、产品开发注意事项

1. 尚无全国统一标准，各地差异大
2. 建议作为市政设计模块的"海绵附加"选项
3. 可按投资额比例或面积单价两种方式提供
4. 一期MVP可简化：市政设计费 × 1.1~1.2（海绵附加系数）
