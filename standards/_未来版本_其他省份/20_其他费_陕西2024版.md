## 一、陕西省建设工程其他费用定额（2024版）

**发文**: 陕西省发展和改革委员会

**执行**: 2025年1月1日起

## 二、市政工程投资估算编制办法

**文号**: 建标[2007]164号
**发文**: 建设部
**日期**: 2007年

规定了市政工程投资估算中其他费用的取费标准，包括：
- 征地拆迁费
- 管线迁改费
- 交通疏解费
- 绿化迁移费
- 临时用水用电费
等市政工程特有的其他费用项目。

## 三、产品开发注意事项

1. 各省其他费定额各有差异（陕西2024版/广东版/江苏版等）
2. 其他费 = 建设用地费 + 建设管理费 + 前期咨询费 + 勘察设计费 + 监理费 + 招标代理费 + 环评费 + 造价咨询费 + 审图费 + 保险费 + 场地准备费 + ...
3. 这些费用在1Hcalc中分别对应不同模块，可统一汇总到"工程建设其他费汇总表"
4. 一期MVP：支持陕西/广东两省即可
